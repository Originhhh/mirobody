# Mirobody 1.5.8 发布验收

## 目标与来源

以已合并的 harness PR #169、前端 PR #12 为基础完成 1.5.8 打包、发布和文档站同步。版本与来源必须在 Python 包、Docker、MCP 注册项和文档锁定文件之间一致。

## 发布顺序

1. 在独立工作目录准备版本 PR，保留其他工作目录中的未提交修改。
2. 完成源码、独立 Python 安装和 Docker 运行验收。
3. 版本 PR 通过 CI 后保留为可合并状态，由发布者合并并使用合并后的固定提交创建版本标签。
4. 文档仓库固定到本次审查的候选提交，更新生成页面和中英文手写说明，验证后通过 PR 合并。候选文档不代表 PyPI 包或 Docker 镜像已经发布。
5. 正式发布由发布者操作：验证 PyPI 发布和 Docker 双架构镜像，下载正式产物复核版本与基本行为，并在发布后将文档锁定提交更新为正式发布提交。

2026-10-22 发布范围确认：本轮完成发布准备和文档 PR 合并；不创建或推送版本标签，不触发正式 PyPI、Docker Hub 或 MCP Registry 发布。

## 验收边界

真实模型的 100 题评分和硬件 TTFT 测量单独记录，不能以编译、安装或脚本模型测试代替。本次发布不宣称已经获得新的真实模型性能分数。停止接收仍不等于取消服务端后台生成。

所有运行验收仅使用合成数据及独立测试服务。文档站从主干自动发布；包和镜像通过仓库现有发布流程生成。
